## 更新方法

Claude Design で編集 → Export HTML →「Standalone HTML」で書き出し。
書き出したファイルはフォントが丸ごと埋め込まれ22MB前後になるため、
軽量化（フォントをGoogle Fonts参照に戻す／画像をdata URI化）の処理が必要です。
